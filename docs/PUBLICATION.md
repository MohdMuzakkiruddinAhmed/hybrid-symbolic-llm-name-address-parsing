# Publication provenance

The 19 predictive Python files and every registered corpus artifact retain the bytes and checksums recorded by the original local protocol. The protocol was frozen locally before final evaluation; no public preregistration is claimed.

This is a publication export. The protocol JSON adds publication metadata and uses neutral annotation names, so its full-file checksum differs from the original protocol. `publication.original_protocol_sha256` records the original checksum; `predictive_source_sha256` and `data_manifest_sha256` remain unchanged. This export does not pretend that newly written packaging documentation was part of the earlier freeze.

Publication text files use LF line endings so the Git tree, source distribution and publication file manifest agree across operating systems. The frozen predictive files already use LF and retain their original bytes; scientific archives retain their existing checksums.

Scientific outputs preserve response text, token mappings, field values, status, model settings, cohort membership, numerical metrics and cost estimates. Annotation field/path names use generic model-assisted terminology. The actual review model, two-pass input-only method, zero human labels, disagreements and uncertainty remain documented. Request/session identifiers and local authentication or launcher metadata are omitted. No claim of independent human verification is introduced.

The legacy reference file contains AST-extracted constants, records and validator functions, without notebook setup or historical live inference. Approval-parity tests use those same definitions. The original Word manuscript and local session logs are not distributed.

Offline analysis adapters use the released aggregate cost snapshot instead of a private SQLite spending database. Their hashes therefore differ from the local analysis scripts; the frozen predictive code is unchanged. The corpus manifest keeps its historical builder hash; the recorded later builder reproduces all 13 data artifacts byte for byte. Old construction metadata saying review was pending is historical; the active model-assisted audit policy is in the protocol and annotation documentation.

The numerical verifier checks all 17 static comparators, final-bank IDs, 294 policy evaluations, reference counts and the accounting total. No additional provider calls or outcome-dependent selection are performed by publication preparation.
